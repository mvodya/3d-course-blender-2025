# Лабораторная 9.2

Гуманоидный персонаж: риг, скининг и анимация

## Требования

Создать гуманоидного персонажа по референсу, сделать для него риг, настроить скининг и анимировать <u>одно</u> действие.

### Референс

* Необходимо найти или нарисовать референс персонажа
* Персонаж должен быть гуманоидом
* У персонажа должны читаться голова, туловище, две руки и две ноги
* Референс должен быть представлен вместе с работой
* Допускается использовать собственный рисунок, фотографию, изображение из интернета или комбинацию референсов

[Набор референсов (можно использовать)](../assets/3d-body-refs/)

Файлы формата .pur открываются в [Pure Ref](https://www.pureref.com)

### Модель персонажа

* Персонаж должен быть смоделирован самостоятельно
* Персонаж должен соответствовать выбранному референсу
* Стиль персонажа может быть любым: реалистичный, cartoon, low poly, робот, монстр, стилизованная фигура и т.д.
* Персонаж может быть простым или сложным, но должен оставаться гуманоидом
* Перед ригом персонаж должен быть подготовлен в `A-pose` или `T-pose` (референс может быть в любой позе)
* Руки не должны быть прижаты к телу
* Ноги не должны пересекаться
* Все основные объекты должны быть названы
* Масштаб модели должен быть применен (`Ctrl + A -> Scale`)

Работа, сделанная только из нескольких примитивов с минимальной трансформацией, не принимается.

### Риг

* Для персонажа необходимо создать `Armature`
* Риг должен соответствовать структуре персонажа
* У рига должны быть кости для основных частей тела:
  * туловище / позвоночник
  * голова
  * руки
  * ноги

* Кости должны быть расположены логично относительно модели
* Суставы костей должны находиться в местах предполагаемых сгибов
* Основные кости должны быть названы

Допускается использовать `Rigify`, но это не является обязательным требованием.

### Скининг

* Модель должна быть привязана к арматуре
* Для привязки можно использовать автоматические веса (`With Automatic Weights`)
* Веса должны быть проверены и исправлены при необходимости (с помощью Weight Paint)
* При движении костей модель должна деформироваться без серьезных артефактов
* Не должно быть частей модели, которые случайно двигаются от неправильной кости

Минимально необходимо проверить деформации:

* плеч
* локтей
* таза
* коленей
* шеи / головы

### Анимация

* Необходимо создать одну законченную анимацию действия персонажа
* Анимация должна быть сделана через кости в `Pose Mode`
* Длина анимации: минимум `60` кадров
* Действие может быть любым, например:
  * бег
  * прыжок
  * удар
  * взмах рукой
  * приседание
  * танцевальное движение
  * шаг

* В анимации должны двигаться <u>минимум корпус</u>, одна рука и одна нога
* Ключевые кадры должны быть расставлены осмысленно
* Движение должно читаться как выбранное действие

### Материалы и внешний вид

* У персонажа должны быть настроены материалы или цвета объектов
* Персонаж должен визуально читаться на сцене
* Камера должна быть настроена так, чтобы было видно движение персонажа
* Освещение должно позволять рассмотреть модель и анимацию

### Ограничения

* Нельзя сдавать готовую скачанную модель персонажа без самостоятельного моделирования
* Нельзя сдавать готовый скачанный риг без самостоятельной настройки под модель
* Нельзя анимировать только объект целиком без костной анимации
* Нельзя оставлять автоматические веса без проверки, если деформации явно ломаются

## Итог

Работа должна содержать:

* `.blend` файл с моделью персонажа, ригом, скинингом и анимацией
* Референс персонажа
* Итоговый рендер анимации или видеофайл с анимацией (не обязательно, но предпочтительно)
* Все внешние зависимости должны быть упакованы в `.blend` файл

# Лабораторная 9.3

Сделать кирпичную стену и анимацию сноса этой стены с помощью шара (либо шар на цепи, либо скатывающийся шар с горки)

Требования:

* Крипичей должно быть много (одна стена с стандартной кирпичной кладкой)
* Все размеры должны быть реалистичными
* У всех твердых объектов должен быть корректный вес
* В сцене должна быть земля (и через нее не должны проваливаться объекты)
* Все кирпичи и шар должны быть с физикой
* При попадании шара в стену, кирпичи должны разлететься
* В сцене должены быть настроены свет и камера
* Сделать фиксацию камеры на шаре (чтобы камера за ним следила) через Constraints

Доп требования (обязательные):

Добавить в сцену кусок ткани, котоый будет взаимодействовать с шаром (придумать самостоятельно как именно).

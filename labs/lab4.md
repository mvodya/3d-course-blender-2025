# Лабораторная 4

Моделирование мягкой игрушки

## Требования

* Смоделировать мягкую игрушку по реальному референсу
* В качестве референса необходимо использовать собственную игрушку
* Если своей игрушки нет — необходимо получить фотографии игрушки другого человека (сокурсника)

### Требования к референсам

* Референсы должны быть сохранены и представлены вместе с работой
* Должно быть несколько фотографий игрушки
* Фотографии должны быть сделаны с разных ракурсов (например: спереди, сбоку, сзади, сверху)
* Использование изображений из интернета запрещено
* Игрушка не должна быть слишком простой (если для ее создания достаточно 1-3 примитивов с минимальной трансформацией, такая работа не будет принята)

### Требования к модели

* Игрушка должна быть узнаваемой и соответствовать референсу
* Основная поверхность игрушки должна состоять не более чем из 4 отдельных мешей
* Одежда, волосы и аксессуары не учитываются в этом ограничении
* Геометрия должна иметь чистую топологию
* Предпочтительно использовать quad-топологию
* Не допускается хаотичная или неаккуратная сетка
* Smooth шейдинга на гладких поверхностях (определяются по референсу)

Работа сделанная просто из примитивов с минимальным редактированием не принимается (даже если соответствует вашему референсу - найдите игрушку сложнее)

### Требования по инструментам

В работе необходимо использовать (минимум):

* Mirror Modifier
* Subdivision Surface

Модификаторы должны использоваться осмысленно, а не формально.

### Требования к сцене

* Все объекты должны иметь названия
* Масштаб модели должен быть близок к реальному размеру игрушки
* Нормали геометрии должны быть корректными
* Использовать Shade Flat / Shade Smooth там, где это необходимо
* Масштаб объектов должен быть применен (`Ctrl + A -> Scale`)

### Ограничения

* Нельзя использовать материалы
* Допускается использовать только цвет объекта (`Properties -> Viewport Display -> Color`)
* Нельзя использовать изображения из интернета в качестве референсов

### Минимальный состав работы

Работа должна содержать:

* Модель мягкой игрушки
* Сохраненные фотографии референсов
* Сцену с корректно названными объектами

Сохранение референсов в самом Blender не обязательно. Если вы импортировали изображения в Blender, не забудьте из запаковать, используя `File / External Data / Pack Resources`.

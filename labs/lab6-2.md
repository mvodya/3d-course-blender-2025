# Лабораторная 6.2

Процедурные материалы (Shader Editor) для мягкой игрушки

## Требования

* Использовать модель мягкой игрушки из лабораторной 4
* Создать минимум 5 различных материалов
* Каждый материал должен быть процедурным (без использования готовых изображений Image Texture)
* В каждом материале должна быть цепочка не менее 4 нод (не включая шейдер)
* Использовать Shader Editor
* Материалы должны быть логичными и соответствовать объекту (ткань, пластик, шерсть и т.п.)

## Состав работы

Необходимо создать материалы для игрушки, например:

1. Основная ткань (тело)
2. Вторичная ткань (вставки / живот / уши)
3. Глаза
4. Нос
5. Декоративный элемент (например: шов, узор, одежда)

Все материалы должны быть назначены на соответствующие части модели

Разрешается доработать и изменить меш игрушки, если необходимо

## Требования к материалам

Для каждого материала:

* Использовать процедурные текстуры (на выбор):

  * Noise Texture
  * Voronoi Texture
  * Wave Texture
  * Gradient Texture
* Использовать ноды преобразования:

  * ColorRamp
  * Mix
  * Math
* Использовать координаты:

  * Texture Coordinate (UV / Object)

### Минимальная структура материала

Каждый материал может содержать цепочку вида:

```
Texture Coordinate -> Texture -> ColorRamp -> Mix/Math -> Principled BSDF
```

(допускается более сложная структура)

## Пример реализации материалов

### 1. Ткань (основа игрушки)

* Noise Texture -> ColorRamp -> Base Color
* Noise Texture -> Math -> Roughness

Эффект: мягкая неоднородная ткань

### 2. Вставки (другая ткань)

* Voronoi Texture -> ColorRamp -> Mix -> Base Color

Эффект: пятнистая структура

### 3. Глаза

* Gradient Texture -> ColorRamp -> Base Color
* Fresnel -> Mix -> Roughness

Эффект: плавный градиент + блик

### 4. Нос

* Noise Texture -> ColorRamp -> Base Color
* Math -> Roughness

Эффект: матовый пластик

### 5. Швы / узор

* Wave Texture -> ColorRamp -> Mix -> Base Color

Эффект: линии / швы на ткани

## Требования к сцене

* Все материалы должны быть названы:

  * `Mat_Fabric_Main`
  * `Mat_Fabric_Secondary`
  * `Mat_Eyes`
  * `Mat_Nose`
  * `Mat_Decor`
* Все материалы должны быть назначены на соответствующие части модели (слоты)
* Использовать UV или Object координаты
* Не допускается использование Image Texture (кроме тестовых UV Grid)

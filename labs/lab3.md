# Лабораторная 3

Моделирование сундука с сокровищами с использованием модификаторов

Создать сцену с сундуком с сокровищами. Сундук может быть выполнен в любом стиле:

**Примеры стилей:**

* DnD / фэнтези (дерево, металлические накладки, магические кристаллы)
* Sci-Fi (технологичный контейнер с панелями и замками)
* Пиратский сундук
* Магический артефакт
* Постапокалиптический контейнер

Сундук должен быть закрытым или приоткрытым. Крышка должна корректно открываться вращением.

## Требования

### Требования к модели сундука

Сундук состоит минимум из:

* Основание
* Крышка
* Петли
* Замок / защелка

Крышка должна:

* Иметь корректно установленный Origin
* Открываться вращением по логичной оси
* При Alt + R возвращаться в закрытое положение
* Все объекты должны иметь логично установленный Origin
* Размер сундука должен быть близок к реальному (примерно 40–90 см в ширину)

### Требования к сокровищам внутри

Внутри сундука должно находиться минимум 4 разных типа предметов:

Примеры:

* Монеты
* Кристаллы
* Слитки золота
* Купюры / деньги
* Драгоценные камни
* Магический артефакт
* Оружие / кинжал
* Технологический чип (для sci-fi версии)

Количество предметов не ограничено, но должно быть **не менее 4 разных видов**

### Требования по модификаторам

* В сцене должно быть **минимум 2 объекта**, использующих композицию из **минимум 3 модификаторов**
* Разрешается использовать любые изученные модификаторы:
  * Mirror
  * Array
  * Bevel
  * Subdivision Surface
  * Solidify
  * Cast
  * Boolean
  * и другие
* Для сундука обязательно применение Subdivision Surface и (или) Mirror

> ⚠️ Если вы применяете модификаторы (`Ctrl + A`) - необходимо: сделать скриншот стека модификаторов или быть готовым подробно объяснить порядок их применения и назначение каждого

### Прочие требования

* Не использовать материалы, использовать только цвет объекта (`Properties -> Viewport Display -> Color`)
* Все объекты должны быть названы (например: `Chest_Base`, `Chest_Lid`, `Coin`, `Crystal`, `Lock`)
* Нормали должны быть корректными
* Использовать `Shade Flat` / `Shade Smooth` там, где это логично
* Масштаб объектов должен быть применен (`Ctrl + A -> Scale`)
* Не допускается пересечение геометрии там, где это не оправдано
* Логичная иерархия объектов (правильное наследование, крышка должна быть дочерним объектом основания и т.п.)

### Минимальный состав сцены

* Сундук (основание + крышка)
* Замок или декоративные элементы
* Минимум 4 разных типа предметов внутри
* Минимум 2 объекта с композицией из 3+ модификаторов

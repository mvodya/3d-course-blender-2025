# Финальная лабораторная

Групповая финальная сцена

## Общие требования

Работа выполняется командой от 2 до 4 человек. Команда выбирает одну из трех тем и создает законченную 3D-сцену в Blender

Оценка за работу выставляется общая для всей команды

Работа должна выглядеть как цельная сцена, а не как набор отдельных моделей. Важно качество композиции, материалов, освещения, ракурса и итогового рендера (это оценивается)

## Темы на выбор

|  #  | Тема                  | Описание                                                                                                  |
| :-: | --------------------- | --------------------------------------------------------------------------------------------------------- |
|  1  | Пляж                  | Песок, пальмы, вода, деревянный или бамбуковый домик, игровая площадка с волейбольной сеткой и мячами     |
|  2  | Кафе / общепит        | Помещение с множеством комнат, барная стойка, стулья, столы, посуда, элементы интерьера, настроенный свет |
|  3  | Городской перекресток | Дома, дорога, автомобили, фонари, дорожная разметка, велосипеды (внутренности зданий не нужны)            |

## Требования к сцене

- В сцене должно быть не менее 20 осмысленных объектов или составных моделей
- Все объекты должны быть смоделированы самостоятельно
- Все объекты должны иметь осмысленные названия
- Масштаб сцены должен быть реалистичным и визуально согласованным
- Не должно быть случайных пересечений геометрии, проваливания объектов или хаотичного размещения

## Минимальный состав по темам

| Тема        | Обязательные элементы                                                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Пляж        | Береговая линия, песок, вода, минимум 3 пальмы, домик из дерева или бамбука, волейбольная сетка, минимум 2 мяча, дополнительные пляжные элементы |
| Кафе        | Барная стойка, минимум 4 стула, минимум 2 стола, посуда, меню или вывеска, источники света, декоративные элементы интерьера                      |
| Перекресток | Дорога с разметкой, минимум 3 здания, минимум 2 автомобиля, фонари, светофор или дорожные знаки, велосипед или велопарковка, тротуары            |

## Моделирование

- Использовать Edit Mode, модификаторы и дублирование там, где это оправдано
- Для повторяющихся элементов использовать массивы, инстансы или Geometry Nodes
- В сцене должен быть минимум один процедурный или параметрический элемент
- Примеры: забор, плитка, окна здания, дорожная разметка, пальмовые листья, стулья, посуда, волны, песок, камни
- Геометрия должна быть чистой, без заметных артефактов
- Для сглаженных объектов использовать `Shade Smooth`, `Auto Smooth`, `Subdivision Surface` или Bevel там, где это необходимо

## UV и материалы

- Для ключевых объектов с материалами должна быть выполнена UV-развертка
- Все основные материалы должны быть PBR
- Для PBR-материалов использовать минимум `Base Color`, `Roughness`, `Normal`
- Желательно использовать дополнительные карты: `Metallic`, `AO`, `Height`
- Материалы должны соответствовать объектам: дерево, песок, вода, ткань, металл, стекло, асфальт, керамика и т.д.
- Все материалы должны быть названы
- Все внешние текстуры должны быть упакованы в `.blend` файл

## Свет, камера и рендер

- В сцене должен быть настроен свет, соответствующий выбранной теме
- Для дневной сцены использовать солнце, небо и дополнительные источники при необходимости
- Для кафе обязательно настроить интерьерное освещение
- В сцене должна быть минимум одна основная камера с продуманным ракурсом
- Итоговые рендеры должны быть выполнены в Cycles или EEVEE
- Не допускается пересвет, полная темнота, шумный рендер без необходимости или нечитаемая композиция
- Желательно использовать DoF, цветокоррекцию, виньетирование или композитинг

## Что сдается

- Один `.blend` файл со всей сценой
- Минимум 3 финальных рендера с разных ракурсов
- Один главный рендер, который считается основным итоговым изображением
- Скриншот или рендер общего вида сцены сверху / из viewport
- Все внешние зависимости должны быть упакованы в `.blend` файл
- Краткое описание вклада команды: кто за какие части отвечал

## Критерии оценки

| Критерий                           |   % | Что оценивается                                                                         |
| ---------------------------------- | --: | --------------------------------------------------------------------------------------- |
| Полнота сцены                      |  15 | Наличие всех обязательных элементов, объем работы, цельность сцены                      |
| Качество моделирования             |  20 | Аккуратная геометрия, пропорции, детализация, отсутствие артефактов                     |
| Материалы и UV                     |  15 | PBR-материалы, UV-развертка, логичность текстур, качество поверхностей                  |
| Свет и рендер                      |  15 | Освещение, тени, читаемость сцены, качество итогового изображения                       |
| Композиция и ракурс                |  10 | Хороший главный кадр, глубина сцены, визуальный баланс                                  |
| Процедурность и технические приемы |  10 | Geometry Nodes, модификаторы, инстансы, грамотное использование повторяющихся элементов |
| Организация файла                  |   5 | Названия объектов, коллекции, порядок в сцене, упакованные зависимости                  |
| Общее художественное впечатление   |  10 | Насколько сцена выглядит законченной, выразительной и аккуратной                        |

## Штрафы

| Нарушение                                                    | Штраф %               |
| ------------------------------------------------------------ | --------------------- |
| Не упакованы текстуры или ассеты                             | до -20                |
| Работа выглядит как набор несвязанных моделей                | до -20                |
| Значительная часть ключевых объектов взята готовыми ассетами | до -30                |
| Нет итоговых рендеров                                        | до -25                |
| Нет PBR-материалов на основных объектах                      | до -20                |
| Сцена не соответствует выбранной теме                        | до -30                |
| Файл невозможно открыть или проверить                        | работа не принимается |

| -------- | ------------------------------------------------------- |

| 2        | Второстепенные модели, декор, повторяющиеся элементы    |

Это распределение не обязательно, но помогает избежать ситуации, когда сцена собрана неравномерно (с разным стилем и т.п.)

## Доп баллы

Не плюсуются выше 100%, но помогают компенсировать штрафы и прочие недочеты.

- Размещение всех объектов из Blender в игровом движке (UE, Unity, Godot)
- Анимация множества объектов на сцене (машины, растительность, персонажи)
- Рендер анимации с пролетом камеры
- Применение физики на сцене (разрушения, ткани, вода и т.п.)
